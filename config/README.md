# 系统配置

本页说明配置入口、填写要求和生效方式。安装与首次使用见[快速开始](../README.md#快速开始)，完整环境变量示例见 [.env.example](../.env.example)。

## 在哪里配置

| 入口 | 用途 | 生效方式 |
| --- | --- | --- |
| `.env` 或部署环境变量 | 数据库连接、部署参数，以及需要固定的平台参数 | 修改后重启服务 |
| 管理端 | 学习平台、YYB 服务、账号分配、资源同步与主题 | 保存后生效 |
| [system.json](system.json) | 系统通用默认值与公开的科目、目录缓存参数 | 运行参数修改后重启；公开前端参数修改后重新构建 |

运行服务前必须填写 `DATABASE_URL` 和 `STUDY_SCHEMA_PREFIX`。前者为 PostgreSQL 连接地址，后者为 1–54 位小写字母、数字或下划线，并以字母开头，例如 `study`。前端构建不需要连接数据库。

## 平台参数的优先级

每个字段分别按“已定义的环境变量 → 管理端保存值 → 默认值”取值。新环境默认关闭两科学习平台，启用前需补齐相应连接参数。

- 环境变量已定义时，管理端标为“系统预设”，不能在页面修改或清空。删除或注释该变量并重启后，可交回管理端维护。
- 空字符串也属于已定义值，可用于清空可选项；必填地址、开关和编号仍须符合格式要求。
- 平台配置中可编辑的密钥和密码留空时保留，输入新值时替换；勾选“清空此项”并保存后移除。

环境变量只影响实际取值，不会改写管理端保存的配置。管理端保存也不会改写 `.env` 或 `system.json`。修改 `.env` 后重启 `npm run dev` 或 `npm start`；管理端保存的修改用于后续请求。

默认 YYB 服务的地址和 API Key 同样遵循上述规则，尚未单独配置时沿用已有 YYB 默认配置。新增服务使用各自的地址和密钥，不受默认服务环境变量影响；服务启用状态与账号分配在“账号与服务”中维护。个人中心的账号关联由学习者单独设置，使用说明见[记录导入](../README.md#导入已有学习记录)。

更换 YYB 服务地址后，管理端保存的旧 API Key 不再沿用，需要认证时重新填写；由环境变量固定的密钥仍按环境值生效。

## 环境变量

| 分组 | 变量 |
| --- | --- |
| 数据库与部署 | `DATABASE_URL`、`STUDY_SCHEMA_PREFIX`、`HOST`、`PORT`、`COOKIE_SECURE` |
| 默认 YYB 服务 | `YYB_BASE_URL`、`YYB_API_KEY` |
| 考研数学 | `MATH_ENABLED`、`MATH_BASE_URL`、`MATH_APP_ID`、`MATH_STATION_ID`、`MATH_LOGIN_ID` |
| 数学拍照搜题 | `MATH_OCR_URL`、`MATH_OCR_USERNAME`、`MATH_OCR_PASSWORD` |
| 计算机 408 | `COMPUTER_ENABLED`、`COMPUTER_BASE_URL`、`COMPUTER_APP_ID`、`COMPUTER_TENANT_CODE`、`COMPUTER_OAUTH_CLIENT_ID`、`COMPUTER_OAUTH_CLIENT_SECRET` |
| 计算机录播 | `COMPUTER_VIDEO_KEY`、`COMPUTER_VIDEO_IV` |
| 数学外部页面与导出 | `MATH_EXTERNAL_URL`、`MATH_PRINT_STATION_ID` |

填写时注意：

- `MATH_ENABLED`、`COMPUTER_ENABLED`、`COOKIE_SECURE` 接受 `0`、`1`、`false`、`true`。
- 平台和 YYB 地址填写完整 HTTP 或 HTTPS 服务根地址，OCR 填写完整接口地址。地址不能包含用户名、密码、查询参数或片段；分别使用服务提供方给出的地址。
- 小程序 App ID 为 `wx` 加 16 位十六进制字符；数学站点、登录编号及 `MATH_PRINT_STATION_ID` 为正整数。
- 录播 AES Key 和 IV 均为 16 字节 UTF-8 文本。
- `MATH_EXTERNAL_URL` 填写以 `/` 结尾的页面 URL 前缀。未配置时，相关外部导出功能不可用。

`MATH_EXTERNAL_URL` 和 `MATH_PRINT_STATION_ID` 仅通过环境变量维护，修改后重启服务。密钥和密码保留在 `.env` 或管理端，无需放入 `VITE_*`。

生产服务默认监听 `127.0.0.1:3001`，可用 `HOST`、`PORT` 调整。HTTPS 部署设置 `COOKIE_SECURE=1`，反向代理保留原始 `Host`。

## 资源渐进式同步

在管理端“资源中心”开启同步并设置公共资源复核期限。默认 30 天，可填写 1–3650 天的整数，保存后生效。

复核期限决定何时建议更新，不是内容失效时间。达到期限或标记“需更新”的公共资源仍可直接使用；开启同步后，系统会在访问时尝试后台更新。YYB 暂不可用时，已有公共内容仍可阅读，缺失内容需要等待获取。

调整期限会按最近同步时间重新计算建议更新时间，已标记“需更新”或没有复核时间的资源仍保持待复核状态。关闭同步后停止自动保存和后台更新，已有资源与学习记录保留。

同步随实际访问进行，不会触发定时抓取。账号相关和实时资源仍按访问获取；个人记录导入使用单独的开关。更多说明见[资源更新与记录导入](../README.md#资源更新与记录导入)。

## 主题与外观

管理端“主题与外观”可分别设置数学、408 的主题色，并统一选择跟随系统、浅色或深色模式。默认数学为鸢尾紫、408 为松石绿，明暗跟随系统；管理空间保持紫色，使用相同的明暗模式。修改后保存即可生效。

学习端顶栏可为两科分别选择个人主题色，两科共用一个明暗模式，也可使用默认设置。个人选择即时生效，仅保存在当前浏览器，不随账号同步，也不影响管理端。浏览器无法保存偏好时，页面会提示本次选择仅临时生效。

## 系统默认值

[system.json](system.json) 的 `runtime` 保存监听地址、数据库连接池、会话时长、资源复核默认周期、超时和诊断等通用参数；`public` 保存科目与目录缓存参数。实际平台地址、App ID 和凭据通过 `.env` 或管理端维护。

新增配置沿用这些入口，并补充校验与说明。开发及真实接口验收流程见[开发指南](../CONTRIBUTING.md)。
