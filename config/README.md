# 系统配置

Web 系统只读取本目录的配置文件、明确设置的环境变量及管理端持久配置。原小程序源码、`yyb.txt` 和历史验收材料属于开发资产，不参与运行时配置。

## 文件与优先级

| 文件 | 内容 | 是否提交 |
| --- | --- | --- |
| `defaults.json` | HTTP、数据库池、会话、同步缓存、超时、诊断及平台初始默认值 | 是；秘密字段为空 |
| `public.json` | 外部打印地址、播放器 SDK、默认科目、默认头像及浏览器目录缓存参数 | 是；会进入浏览器构建 |
| `local.example.json` | 本机配置模板，只包含示例地址与空秘密 | 是 |
| `local.json` | 本机数据库、YYB、OAuth、OCR 与录播配置，可只填写需要覆盖的字段 | 否 |

服务端配置的优先级是：`defaults.json` → 一份部署文件 → 环境变量。部署文件默认为 `config/local.json`；设置 `STUDY_CONFIG_FILE` 后使用该文件替代本机文件。相对路径以仓库根为基准。默认本机文件可不存在，明确指定的文件不存在或格式不正确则启动失败。

```sh
cp config/local.example.json config/local.json
# 填写数据库连接、YYB 地址及所需平台秘密
npm ci
npm run dev
```

也可通过 `.env` 提供覆盖项，支持的变量见[环境变量模板](../.env.example)。本机文件及 `.env` 只用于服务端；浏览器模块只能导入 `public.json`。

## 运维配置

`defaults.json` 的 `runtime` 包含以下分组，完整字段以文件为准：

- `http`：监听地址、端口、JSON/上传大小及哈希静态资源缓存。
- `development`：Vite 监听地址、端口与文件访问限制；API 代理地址由服务端监听配置推导。默认限制保留环境/证书文件保护，并阻断服务端配置，选定的部署文件也会自动加入拒绝列表。
- `database`：连接 URL、schema 前缀、连接池大小及连接超时。
- `session`：会话有效期和安全 cookie。
- `resources`、`accounts`：公共资源有效期、YYB 目录复用和账号分配有效期。
- `upstream`、`diagnostics`：外部请求/头像超时和诊断保留条数。

运维文件更改后重启相应进程。环境变量 `DATABASE_URL`、`STUDY_SCHEMA_PREFIX`、`HOST`、`PORT`、`COOKIE_SECURE` 继续有效。

## 平台初始配置与管理端

`platforms` 的 `yyb`、`math`、`computer` 提供配置数据库首次创建时的初值。已存在的持久平台配置继续由管理空间维护，文件或环境变量不会覆盖管理员已保存的值，也不会恢复已明确清空的秘密。

新环境需要填写实际 YYB 地址及可选 API Key；按使用范围配置数学 OCR 用户名/密码、计算机 OAuth 客户端密钥及录播 AES Key/IV。录播 Key/IV 需要 16 字节 UTF-8 值。示例文件不包含可用秘密，运行时也不会再从开发资产提取。

数学站点由服务端按当前平台配置注入请求；浏览器及验收脚本不再各自保存一个站点固定值。`public.json` 中的 `math.printStationId` 属于外部打印服务的参数，可独立设置。

## 公开配置

`public.json` 被前端直接引用，改动后重新构建前端；默认头像也由服务端引用，改动后重启服务端。此文件不能保存数据库、YYB 密钥、OAuth 秘密或录播解密秘密。

API 路径、字段名、协议编码、业务枚举及算法常量由代码定义，不作为部署参数配置。结构检查会拒绝浏览器引用服务端配置，构建检查也会核对实际产物没有带入非公开配置模块。
